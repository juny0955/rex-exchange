# 주문 조합 규칙

## 개요

본 문서는 매칭 엔진에서 지원하는 주문 타입(OrderType), 주문 방향(Side), 주문 유효 시간(TimeInForce), 수량 입력 방식(Quantity Mode)의 조합 규칙을 정의한다.

---

| --- | -------- | --------- |

| FOK | O        | O         |

# 미지원 조합

| OrderType               | Side                                                        | 사유 |
| ----------------------- | ----------------------------------------------------------- | ---- |
| LIMIT SELL + quote_qty  | 목표 quote 금액 기준 매도는 체결 및 잔량 계산 복잡도가 높음 |      |
| MARKET SELL + quote_qty | 시장가 특성상 목표 quote 수취 금액 보장이 어려움            |      |
| MARKET + GTC            | 시장가 주문은 오더북에 잔존하지 않음                        |      |

---

# 처리 정책

## LIMIT BUY + quote_qty

`LIMIT BUY + quote_qty` 주문은 엔진 진입 전 Base Quantity로 변환한다.

예시:

```text
LIMIT BUY
price = 50000
quote_qty = 1000
```

변환:

```text
quantity = quote_qty / price
```

---

## MARKET BUY + quote_qty

`MARKET BUY + quote_qty`는 사전 quantity 계산이 불가능하다.

호가를 순차적으로 consume 하며 남은 quote 잔액 기준으로 체결한다.

예시:

```text
MARKET BUY
quote_qty = 1000
```

처리 흐름:

1. 최우선 매도 호가 체결
2. 사용한 quote 금액 차감
3. 남은 quote 기준 다음 호가 체결
4. quote_qty 소진 시 주문 종료
