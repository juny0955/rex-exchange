## 판정

- 최신 안정 TPS는 `100,000`이다. 측정 구간에서 `채널 포화 = 0`, `완료 여부 = 예`, `발행 결과 = 접수 성공`을 만족하며 p99 지연이 `868µs`로 1ms 미만이다.
- 경계 TPS는 `110,000`이다. 측정 구간에서 `채널 포화 1,995`가 발생하며 p99 지연이 `1.675ms`로 1ms를 초과하기 시작하는 지점이다.
- 초과 구간은 `120,000+`이다. `120,000`에서 `채널 포화 5,752`와 함께 p99 지연이 `4.535ms`로 급증하여 런타임 포화가 뚜렷하다.
- 본 시나리오는 GTC 주문이 orderbook에 누적되는 non-stationary 특성을 가진다. 측정 시간(30s) 동안 주문이 누적되었음에도 100,000 target/s까지 안정적으로 처리됨을 확인했다.
- `full-fill-same-level` 대비 p99 지연이 소폭 낮으며, 이는 체결 후 잔량이 남는 로직이 전량 체결 로직보다 현재 부하 조건에서 소폭 효율적으로 동작함을 시사한다.
