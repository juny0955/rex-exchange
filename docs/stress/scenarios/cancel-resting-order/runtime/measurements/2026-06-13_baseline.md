## 판정

- 최신 안정 TPS는 `90,000`이다. `채널 포화 = 0`, `완료 여부 = 예`, `발행 결과 = 접수 성공`을 만족하며 p99 지연이 `374µs`로 매우 안정적이다.
- 경계 TPS는 `100,000`이다. `채널 포화 321`이 발생하며 성능 한계에 도달하기 시작하는 지점이다.
- 초과 구간은 `200,000+`이다. `200,000`에서 `채널 포화 6,614`가 발생하며 런타임 포화가 뚜렷해진다.
- `cancel-resting-order` 시나리오는 체결 로직을 타지 않고 orderbook의 삽입/삭제만 수행하므로 `full-fill-same-level` 등의 체결 시나리오보다 높은 처리량(안정 90,000 TPS)을 보여준다.
- 100,000~180,000 구간에서 수백 건 정도의 낮은 채널 포화가 지속적으로 관측되는 특성이 있으나, 안정적인 0 포화 상태는 90,000 TPS까지 유지된다.
