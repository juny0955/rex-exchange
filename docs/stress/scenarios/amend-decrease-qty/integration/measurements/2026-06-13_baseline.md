## 판정

- **안전 TPS = 20,000**. `채널 포화 0건`, `target 달성률 100%`이며 ack p99 `687µs`, E2E p99 `8.294ms`로 안정적이다. 15,000에서도 동일하게 503=0이었으나, 20,000까지 503=0을 유지하는 더 높은 지점을 안전선으로 채택했다.
- **경계 TPS = 25,000**. `target 달성률 100%`는 유지하지만 `채널 포화 14.56%`가 발생하고 ack p99가 `687µs → 32.497ms`(약 47배), E2E p99가 `8.294ms → 67.747ms`(약 8배)로 급증한다.
- **포화 TPS = 30,000**. `채널 포화 36.36%`, `접수 성공률 63.64%`로 명령의 1/3 이상이 거부된다. **초당 접수 성공 수는 19,090.4/s로 25,000 target(21,357.2/s)보다 낮아져** 채널 포화 재시도 비용이 실효 처리량을 깎아먹는 역전 현상이 나타난다. `무손실 판정`은 통과(접수에 성공한 명령은 모두 15초 settle 내 수신).
- commands/unit=3은 commands/unit=1(`place-resting-limit`: 안전 25k/경계 40k/포화 50k+)보다 채널 burst가 커 안전선이 낮고(20k), commands/unit=20(`cancel-resting-order`: 안전 10k/경계 15k/포화 30k+)보다는 burst가 작아 안전선이 높다. 503 기반 포화 패턴은 `cancel-resting-order`와 동일하게 "접수 성공/s가 target 증가에도 오히려 감소"하는 역전 현상을 보인다.
