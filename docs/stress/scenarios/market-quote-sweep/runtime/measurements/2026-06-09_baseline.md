이 문서는 `market-quote-sweep` 시나리오의 첫 기준선을 기록한다.
고정 측정 환경은 [Stress 테스트 홈](../../../../README.md)의 Vultr EPYC-Rome 환경을 사용한다.

## 요약

`market-quote-sweep` 단일 심볼 기준으로 300k commands/s까지는 채널 포화 없이 처리됐다.
330k commands/s는 channel full이 소량 발생했으므로 무손실 안정권이 아니라 경계 구간으로 본다.
350k commands/s는 반복 run에서 channel full이 발생했고, 370k commands/s에서는 accepted/s가 크게 하락했다.

| 항목 | 값 |
| --- | ---: |
| 안정 TPS | 300,000 commands/s |
| 경계 TPS | 330,000 commands/s |
| 초과 구간 | 370,000 commands/s |

## 해석 포인트

- 200k, 250k, 300k는 채널 포화가 없으므로 안정권으로 본다.
- 330k는 channel full이 168건 발생했으므로 경계 구간으로 본다.
- 350k는 반복 run에서 channel full이 발생해 안정권으로 보지 않는다.
- 370k는 dispatch 시도량은 목표에 가깝지만 accepted/s가 약 69k/s까지 떨어져 명확한 초과 구간이다.
- `completed = yes`는 접수된 command가 결과 발행까지 완료됐다는 뜻이다. channel full로 거부된 command가 처리됐다는 의미는 아니다.
