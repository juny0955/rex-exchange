## 판정

- 최신 안정 TPS는 `100,000`이다. `채널 포화 = 0`, `완료 여부 = 예`, `발행 결과 = 접수 성공`을 만족하며 p99 지연이 `792µs`로 안정적이다.
- 초과 구간은 `120,000+`이다. `120,000`에서 `채널 포화 5,873`이 발생하며 포화가 뚜렷해졌다.
- 이전 측정(안정 80,000) 대비 안정 TPS가 `100,000`으로 상향되었다. 이는 실행 시점의 시스템 리소스 상황이나 Docker 컨테이너 스케줄링의 일시적 차이로 보이나, 현재 시점 재측정 결과는 100k까지 안정적임을 보여준다.
